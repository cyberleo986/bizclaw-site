## PR Body

### What is BizClaw?

BizClaw provides production-ready OpenClaw agent SOUL.md templates for business use cases. Instead of building agent configurations from scratch, businesses download pre-configured templates, customize them, and deploy.

### What's included

**Free template:**
- Customer Support Agent — full SOUL.md with support tiers, escalation rules, knowledge base structure, memory schema, edge cases, and quality guardrails

**Paid templates ($19 each):**
- Lead Qualification Agent — sales workflows, CRM integration, prospect research
- Appointment Booking Agent — calendar integration, reminders, rescheduling
- Research & Intel Agent — web search, data analysis, competitor monitoring

**Deploy Package ($49):**
- Docker configuration (Dockerfile + docker-compose.yml)
- Telegram bot integration
- Web chat widget
- Setup instructions

**Managed Service ($29/mo):**
- Fully managed hosting
- Email + web chat + Telegram
- 500 conversations/month

### Why add to this list?

BizClaw is one of the first commercial template marketplaces for OpenClaw agents. The free Customer Support template is a complete, deployable configuration — not a stub. It demonstrates the SOUL.md format and gives developers an immediate starting point.
