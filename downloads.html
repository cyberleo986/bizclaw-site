How It Works

From download to deployed in under 10 minutes. No coding required.

1. Download Template

Pick your agent template, download the package, and unzip it. You get a SOUL.md with all workflows plus a Docker deploy kit.

2. Add Your Keys

Copy .env.example to .env, paste in your API key (OpenAI or Anthropic) and channel credentials (Telegram, email, Slack, etc.).

3. Deploy with Docker

Run docker compose up -d — that's it. Your agent is live and monitoring your channels 24/7.

4. Customize SOUL.md

Edit your business hours, services, pricing, policies, and escalation rules directly in SOUL.md. Restart the container — changes are live.

FAQ

What is OpenClaw?

OpenClaw is an open-source AI agent framework that connects AI models (OpenAI, Anthropic, Ollama) to business channels (email, SMS, Telegram, Slack, web chat). It handles memory, heartbeats, multi-channel routing, and agent personality via SOUL.md files.

Do I need to know how to code?

No. The templates are configuration files (SOUL.md) and Docker configs. You edit text files to customize your agent's behavior and run Docker commands to deploy. The README walks you through every step.

What AI model should I use?

We recommend Anthropic's Claude Sonnet for the best quality-to-cost ratio. OpenAI's GPT-4o also works well. For cost savings, use Claude Haiku or GPT-4o-mini. For privacy, use a local Ollama model.

Can I run multiple agents?

Yes! Each agent runs as its own Docker container. Deploy one for lead qualification, another for appointment booking, etc. They can share the same workspace or run independently.

What does "production-ready" mean?

Each SOUL.md includes complete workflows, qualification frameworks, escalation rules, memory tracking, heartbeat schedules, and channel configurations. The deploy package includes Dockerfile, docker-compose with health checks, persistent volumes, and logging. It's not a demo — it's a real product.

Can I customize the agent after deployment?

Yes. Edit SOUL.md, then restart the container with docker compose restart. All memory and conversation history is preserved in Docker volumes.

What's the difference between free and premium?

The Customer Support Agent is free — it includes the SOUL.md template. Premium templates ($19 each) include the SOUL.md plus the full Docker deploy package (Dockerfile, docker-compose.yml, .env.example, README setup guide).
